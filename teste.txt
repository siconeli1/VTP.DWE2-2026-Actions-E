COMANDOS PARA CONFERIR NA EC2

Entrar na EC2:
ssh ubuntu@100.54.121.237

Ir para o projeto:
cd /var/www/html/hdcevents

Status dos servicos:
sudo systemctl status apache2
sudo systemctl status mysql

Rotas Laravel:
php artisan route:list

Status das migrations:
php artisan migrate:status

Consultar eventos no MySQL:
MYSQL_PWD='SENHA_DO_USUARIO_LARAVELUSER' mysql -ularaveluser -h127.0.0.1 hdcevents -e "SELECT id, title, city, date, image, items FROM events;"


GITHUB ACTIONS

O deploy roda automaticamente quando fizer push na branch main.
Conferir execucoes em:
https://github.com/colavitepedro/VTP.DWE2-2026-Actions-E/actions/workflows/deploy-to-ec2.yml

Secrets necessarios:
EC2_SSH_KEY

Configuracoes no arquivo .github/workflows/deploy-to-ec2.yml:

REMOTE_USER=ubuntu
TARGET=/var/www/html/hdcevents/
APP_URL=http://100.54.121.237
